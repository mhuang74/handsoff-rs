# In-app Setup Wizard replaces the CLI setup flow for average users

The old setup experience required a terminal: run `handsoff --setup`, grant Accessibility to whatever terminal app launched it (misattribution of the TCC prompt), and endure warning popups pointing back at the terminal. We replace this with an in-process Setup Wizard window in the tray app: no config or an invalid one launches the wizard automatically; the wizard requests Accessibility permission first (capture requires a CGEventTap, so permission must precede the passphrase step), captures the passphrase and hotkeys, and offers a login item via SMAppService (replacing the killed .pkg LaunchAgent). The CLI binary and its TUI `--setup` remain unchanged as a separate release artifact for power users. The .pkg pipeline (Makefile `pkg` target, LaunchAgent plist template, installer scripts) is deleted in favor of DMG + CLI distribution. Config validation is strict on every launch: malformed configs route into the wizard/Preferences rather than exiting with an error dialog.
